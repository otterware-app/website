Ready for agents

API keys and the CLI, set up from Settings, so agents publish where you can read.

From your terminal, and your agents.

Publish a report, a spreadsheet or a whole site, and push its next run as a new version. Give your agent the CLI and its key, and what it makes lands where your team can read it.

# once
npm install --global otterdrive
otterdrive auth login

# publish, then every run after is a new version
otterdrive artifacts create ./report.xlsx --slug q3-review --title "Q3 revenue review"
otterdrive artifacts push q3-review ./report.xlsx --label "November close"
otterdrive artifacts versions q3-review

# share it
otterdrive artifacts share q3-review maya@northwind.example --role editor
